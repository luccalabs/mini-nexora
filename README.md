# Mini Nexora

Mini Nexora is a Python learning project focused on building a simplified operational event management system.

The project is being developed incrementally as part of my software engineering and AI development learning roadmap.

## Current features

- Operational event registration
- Event type, priority and description
- Priority validation
- Event listing
- Priority statistics
- High-priority alert filtering

## Current stage

**v0.1 — Baseline**

The current version represents the initial functional baseline of the project. Future iterations will introduce better code organization, functions, persistence, databases, APIs and automated tests.

## Learning objectives

This project is being used to practice:

- Python fundamentals
- Data structures
- Control flow
- Input validation
- Software decomposition
- Git and GitHub
- Incremental software development
